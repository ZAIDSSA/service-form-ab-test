# اختبار A/B لتبسيط نموذج خدمة إلكترونية

**إعداد: زايد الدوسري**

المشروع الختامي لدورة **التجارب واختبارات A/B والاستدلال السببي**، أكاديمية سدايا.

## الوصف والسؤال

هل يرفع نموذج طلب إفادة من 5 حقول بدل 8، مع تعبئة البيانات المعروفة، نسبة تقديم الطلب خلال 24 ساعة؟ نختبر هل تستحق النسخة المبسطة الإطلاق وفق حد عملي ومقياسي حماية.

## التصميم

- تخصيص عشوائي ثابت بنسبة 50/50 على مستوى الحساب. التحليل حسب التخصيص (ITT).
- المقياس الرئيسي: نسبة تقديم الطلب خلال 24 ساعة. الحماية: تذاكر الدعم والإرجاع للتصحيح خلال 7 أيام.
- 22,400 حساب خلال أسبوعين، ثم 7 أيام متابعة. فحص A/A واختلال نسبة التوزيع (SRM)، وتحليل CUPED للحساسية وتصحيح BH للمقاييس الثانوية.
- البيانات مولّدة بالمحاكاة، ببذرة ثابتة. ما فيها سجلات أشخاص أو معاملات فعلية.

## النتائج والتوصية

زادت نسبة الإتمام من **30.81% إلى 31.96%**. الأثر **+1.15 نقطة مئوية** وفترة الثقة 95% **[−0.07، +2.36]**. اجتاز مقياسا الحماية الهامشين، لكن فترة الأثر تشمل عتبة الإطلاق +1 نقطة. **نؤجل الإطلاق ونخطط لتجربة ميدانية بقوة كافية لتجاوز العتبة.**
